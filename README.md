# Carnelian Community Website — Main Site v2

This package upgrades the homepage while preserving the newsletter archive and monthly issue folders.

## What changed
- Uses the polished Carnelian entrance graphic as the homepage hero.
- Adds a dedicated Latest Newsletter feature.
- Adds real community imagery from the HOA Google Drive.
- Adds Around Carnelian, Life at Carnelian, Projects & Improvements, Quick Access, and Contact sections.
- Keeps all important titles/body copy as live HTML text.
- Remains responsive for phones, tablets and desktops.

## Upload to GitHub
1. Unzip this package.
2. In the `carnelian-community` repository choose **Add file → Upload files**.
3. Drag the contents of this folder into the repository.
4. Commit the changes.
5. GitHub Pages will rebuild automatically.

The existing `/newsletters/2026/august/` page and archive remain in the package.

## Monthly workflow
- Add new photos to the private HOA Google Drive.
- Ask ChatGPT to review the current month's photos and draft the newsletter.
- Only selected public-facing photos are copied into the website package.
- Keep homeowner-specific, access-control, financial-detail, and other private Board material off the public site.
